# OpenClaw 基金实盘挑战分支

这是一个仅用于**1000 元场外基金短线激进挑战**的专用分支。

## 挑战目标

- 初始资金：**1000 元**
- 目标：**6 个月翻倍**
- 交易平台：**支付宝 / 天天基金**
- 风格：**短线激进**（但强校验、强风控）

## 本分支包含内容

- `fund_challenge/`：挑战运行文件
- `skills/fund-challenge-*`：挑战专用技能
- 不包含与本挑战无关的代码/工程内容

## 核心原则

1. **状态优先**：状态与流水可追溯、可回放
2. **证据门控**：未通过证据校验，不允许 EXECUTE_READY
3. **执行可行性**：严格考虑场外基金 T+、截止时间、申赎限制
4. **低 token 开销**：紧凑输出、证据瘦身、短指令模板

## 每日流程（交易日）

- **09:00** 健康检查（正常静默，异常告警）
- **14:00** PLAN_ONLY 预案
- **14:48** EXECUTE_READY 最终门控（只给一个可执行方案）
- **20:05** 收盘更新
- **20:25** 轻量复盘
- **21:00** 维护任务（缓存清理）

## 你需要做的事

- 仅在收到 BUY 指令后，在 APP 手动下单
- 执行后回复确认，例如：
  - `我已买入 020899 100元，14:52`
  - `未执行：限购/暂停申购`

## 关键脚本

- `run_decision_pipeline.py`：端到端低 token 决策流水线
- `preflight_guard.py`：预检门控
- `decision_publish_gate.py`：发布硬门
- `confirm_and_apply.py`：一键确认并回写
- `execution_receipt_updater.py`：状态/流水权威更新

## 安全底线

只要关键数据或来源无法验证，必须输出：

`DECISION_ABORTED_UNVERIFIED_DATA`

并降级为 **HOLD**。
