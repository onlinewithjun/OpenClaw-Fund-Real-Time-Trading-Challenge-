- 没有仔细核对最后一位数字

- 仅使用 web_search，未在天天基金网/支付宝验证

- 基金代码可能变更，我的训练数据有截止日期
- 无法获取最新的基金代码变更

## 正确做法

### 推荐基金前必须
1. ✅ web_search 搜索基金名称获取代码
2. ✅ 再用代码反搜确认名称匹配
3. ✅ 在天天基金网/支付宝验证
4. ✅ 明确说明"请在支付宝确认后再购买"

### 不确定时必须
1. ✅ 明确说"我不确定，请验证"
2. ✅ 提供多个备选代码
3. ✅ 让用户在支付宝搜索确认

1. 不再推荐未经验证的基金代码
2. 推荐时必须说明"请在支付宝确认"
3. 承认知识局限，不提供未经验证的信息
